# Cover Brief — International English Edition

## Front-cover hierarchy

**AI**  
**From First Principles to Agentic Systems**

*How AI Actually Works — From LLMs and RAG to Tools, Agents, Evals, and Reliable Systems*

## One-line promise

**Understand the model. Engineer the context. Connect the tools. Verify the result.**

## Visual direction

Restrained technical nonfiction, closer to a serious engineering/systems book than to generic AI marketing.

The visual metaphor should show one model node expanding into a layered system:

```text
MODEL
→ CONTEXT / DATA
→ RETRIEVAL / TOOLS
→ AGENT LOOP
→ VERIFICATION
```

The design should communicate that the model is only one component of the system.

## Requirements

- strong thumbnail readability;
- high contrast;
- minimal geometric language;
- one memorable system/loop motif rather than decorative complexity;
- enough hierarchy for title, subtitle, and author name;
- credible for software engineers, electronics engineers, architects, and technical managers.

## Avoid

- humanoid robots;
- glowing brains;
- fake PCB/circuit-board backgrounds;
- neon cyberpunk imagery;
- stock-photo AI faces;
- visual claims of magical autonomy.

## Back-cover lead

**A powerful model is only the beginning.**

The systems that survive real work need the right context, trustworthy data, tools that can act on the world, permissions that limit what they may do, and a way to verify the result.

## Back-cover close

If an AI demo impresses you, ask five more questions:

**Where does it get its data? What does it actually see? Which tools can it use? What is it allowed to do? And how do we know the result is correct?**
