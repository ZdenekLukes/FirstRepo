## Aktuální stav

Všech **37 hlavních kapitol** je nyní rozepsaných z původních koster do souvislého prvního draftu ve společném stylu knihy:

- technicky správně, ale bez zbytečné matematiky,
- jednoduchý mentální model → praktický příklad → důsledky,
- jasné rozlišení modelu, aplikace a celého AI systému,
- ASCII schémata a praktické workflow,
- na konci každé kapitoly stručné „Co si z kapitoly odnést“,
- návaznost na následující kapitolu.

Rychle se měnící témata jsou označena datem snapshotu a tam, kde je to důležité, obsahují odkazy na aktuální primární zdroje.

Osobní kapitola 34 záměrně neobsahuje vymyšlené zkušenosti; místa pro budoucí konkrétní experimenty jsou viditelně označena k doplnění.

3. Doplnit vlastní konkrétní experimenty do osobních kapitol.
4. Rozpracovat přílohy A–G.
