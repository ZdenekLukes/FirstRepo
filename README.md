## O knize

Hlavní myšlenka knihy je jednoduchá:

> **Nejdůležitější není mít nejchytřejší model, ale umět mu ve správný okamžik dodat správný kontext a nástroje — a jeho výsledek spolehlivě ověřit.**

Kniha začíná úplnými základy a postupně staví celý mentální model moderní AI:

**AI → Machine Learning → Deep Learning → LLM → Context → RAG → Tools → MCP → Agents → Agentic Systems → Evals → Reliable AI Systems**

Cílem není vytvořit katalog produktů ani sbírku promptů. Jde o praktickou technickou knihu, která vysvětluje **jak AI skutečně funguje, kde selhává a jak z pravděpodobnostních modelů stavět systémy použitelné pro skutečnou práci**.

## Co je uvnitř

Každá jazyková edice obsahuje:

- **úvod + 36 číslovaných kapitol**,
- **7 praktických příloh**,
- **43 obrazových diagramů + 43 print variant**,
- modelový a nástrojový snapshot k srpnu 2026,
- praktické části o lokálních LLM, RAG, MCP, tool use a agentech,
- bezpečnost, governance, AI readiness, evaluaci a ekonomiku AI,
- praktickou případovou studii **AI-assisted analog IC design**,
- deset projektů od prvního použití AI až po agentní systém.

Text je záměrně psaný tak, aby byl použitelný pro člověka, který s AI začíná, ale zároveň měl dostatečnou technickou hloubku pro inženýra nebo AI geeka.
